# AJN PDF R25 — Private Workspace Foundation

This branch is the production-hardening and workspace foundation release. It deliberately preserves the existing verified billing, Firebase authentication, public 20-tool allowlist and Cloud Run backend contracts while adding a local-first workspace, clearer operational error handling, account/admin product surfaces and release gates.

Nothing on this branch may claim a processor, native app, team feature, cloud integration or security property that is not implemented and verified.
