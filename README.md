
# AJN STUDIO — Free PDF Tools

AJN Studio is an easy and safe way to work with your documents. All tools run 100% in your browser. Your files never leave your computer.

## 🚀 Live Setup

### 1. Simple Setup
Ensure your environment includes:
- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
- `NEXT_PUBLIC_API_URL` (Points to your Python backend)

### 2. Fast Build
```bash
npm install
npm run build
```

### 3. Reliable Hosting
AJN is optimized for **Firebase App Hosting**.
1. Go to the [Firebase Console](https://console.firebase.google.com/).
2. Select **App Hosting**.
3. Connect your code.
4. Deploy.

## 🏗️ How it Works

- **Frontend**: Next.js 15 (Fast and Easy)
- **Styling**: Tailwind CSS + ShadCN UI
- **Processing**: Python FastAPI + pypdf (Runs in local buffer)
- **Privacy**: All files are deleted automatically from memory.

## 🔒 Your Privacy
AJN Studio does not store your files. Everything happens on your own device. Safe, fast, and always free.
